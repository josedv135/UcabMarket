Como miembro de la comunidad UCAB, quiero crear un chat con el vendedor de un producto, para coordinar la compra por mensajes.Épica: Gestionar chats.

Escenario de uso: El miembro ve el detalle de un producto del catálogo y presiona «Contactar vendedor». El sistema le pide confirmar y, al presionar «Crear chat», crea la conversación privada con el vendedor y se la muestra. Ahí el miembro escribe su mensaje y lo envía, y puede seguir escribiendo. Si el chat no se pudo crear, el sistema avisa y vuelve a preguntar; si el miembro presiona «Salir», se cancela el proceso y regresa a Consultar producto.

Reglas de negocio:
1. Solo pueden crear chats los miembros UCAB con sesión iniciada.
2. El chat no muestra datos personales de ninguno de los dos (correo, teléfono).
3. Solo los dos miembros del chat pueden escribir en él; nadie más puede modificar ni eliminar sus mensajes.

Alcance: Incluye crear el chat desde el detalle del producto, mostrarlo y enviar un mensaje en él. No incluye adjuntar archivos (HU Añadir Archivos).

Dependencias: Crear Cuenta (para tener sesión iniciada); Añadir producto (debe existir un producto publicado); Consultar producto (desde ahí se llega al botón).

Otras restricciones: Solo en español y en web de escritorio. Requisito no funcional (ISO/IEC 25010): Seguridad → Integridad (regla 3 y CA6).

Diagrama de actividades: ver el enlace debajo de esta tabla.		CA1 — Chat creado: Dado que inicié sesión y estoy viendo un producto de otro miembro, cuando presiono «Contactar vendedor» y luego «Crear chat», entonces el sistema muestra «Chat creado» y, al presionar OK, me muestra el chat nuevo con el vendedor.

CA2 — Salir: Dado que el sistema me pide confirmar la creación, me avisa «Chat creado» o me muestra el chat, cuando presiono «Salir» en lugar de «Crear chat», OK o «Enviar», entonces se cancela el proceso y regreso a Consultar producto.

CA3 — Sin datos personales: Dado que se creó el chat, cuando lo veo, entonces se muestran solo los nombres de usuario y el producto, sin el correo ni el teléfono del vendedor ni los míos.

CA4 — Enviar mensaje: Dado que el chat está creado y lo estoy viendo, cuando escribo un mensaje y presiono «Enviar», entonces el sistema muestra mi mensaje actualizado en el chat y puedo seguir escribiendo.

CA5 — No se pudo crear: Dado que presioné «Crear chat», cuando el sistema no puede crear el chat, entonces muestra «No se pudo crear el chat, inténtalo de nuevo» y, al confirmar la lectura, me vuelve a preguntar si deseo crear el chat.

CA6 — Chat protegido: Dado que existe un chat entre dos miembros, cuando otro miembro que no pertenece al chat intenta escribir, modificar o eliminar mensajes en él, entonces el sistema no se lo permite.
